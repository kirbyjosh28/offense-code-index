Accessibility statement

The candidate is designed toward WCAG 2.2 Level AA, with WCAG 2.1 Level AA and IITAA treated as minimum release baselines.

01 / COMMITMENT

Accessible lookup for all users

The design target includes keyboard operation, visible focus, meaningful structure and labels, screen-reader announcements, sufficient contrast, text resizing and reflow, reduced-motion support, forced-colors compatibility, and touch-friendly controls.

02 / STATUS

No certification claim

No independent accessibility audit or Accessibility Conformance Report has been completed. The site must not be described as certified, fully compliant, or independently verified. Automated and code-level checks reduce risk but do not replace testing with disabled users and assistive technologies.

03 / SOURCE DOCUMENTS

External PDF is scoped separately

The source PDF is published and controlled by an external government entity. Its accessibility is assessed separately from this website. The website is intended to expose all 953 extracted records as accessible HTML while preserving links to exact source pages.

04 / FEEDBACK

Report an accessibility barrier

The operator is the Independent Illinois Offense Code Reference project. Report a barrier through https://github.com/kirbyjosh28/offense-code-index/issues. Tracker submissions may be public, so describe the interface barrier without including sensitive information.

Do not include names, plates, identifiers, case details, CJI, or other sensitive information in a report. Owner-reviewed August 10, 2026.
