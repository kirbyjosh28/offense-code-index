# Release compliance evidence

The files in `config/` are machine-readable release controls, not claims of legal certification.

The checked-in configuration is intentionally marked **draft** and blocks production promotion. Before a production build, accountable owners must replace pending values with documented facts and approval references. The release validator checks structure, dates, source/corpus identity, corpus integrity, and the approval gate; it does not replace review by qualified counsel or the purchasing agency.

If source rights, provenance, corpus accuracy, privacy, accessibility, or security is disputed, set the corpus status to `disabled` and publish the configured maintenance message instead of serving questionable results.
