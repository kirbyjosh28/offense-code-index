# Accessibility evidence register

Status: incomplete candidate evidence. This is not an ACR, VPAT, certification, or conformance claim.

Automated/source checks cover semantic landmarks, labels, live regions, keyboard contracts, 44px primary targets, contrast tokens, reduced motion, responsive gutters, and 953-record availability in HTML. A 375×812 browser check verifies bounded search tools and no horizontal page overflow.

Production remains blocked until an independent reviewer documents WCAG 2.2 AA testing with keyboard-only operation, 200% and 400% zoom/320px reflow, forced colors, reduced motion, NVDA/Firefox, JAWS/Chrome, VoiceOver/Safari, and a mobile screen reader. The externally controlled PDF must be scoped separately in the final ACR/VPAT.
